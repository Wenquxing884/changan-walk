# 长安 · 入境

一个可以在浏览器里旋转、缩放、进入街道和宫殿的唐风城市漫游样板。

## 启动

需要 **Node.js 20.19+ 或 22.12+** 与 npm；推荐 Node.js 22 LTS。下载源码后可用 `npm ci` 按锁文件安装依赖。

在项目目录执行：

```powershell
npm install
npm run dev
```

浏览器访问 **http://127.0.0.1:5175/**。也可以双击项目中的 `启动长安漫游.cmd`。

此仓库保存「长安 · 入境」城市漫游版，包含 Three.js 源码、Blender 源文件、运行模型、测试脚本与实测截图；不包含其他景区项目、依赖缓存或本机聊天记录。

场景不需要账号或外部模型服务。Three.js、程序绘制的纹理、Blender 导出的正殿模型均由本地服务器提供；浏览者不需要安装 Blender。部分中文／西文字体会从 Google Fonts 获取，离线时浏览器自动回退本机系统字体。请通过 HTTP 服务器访问，直接双击 `index.html` 无法加载 JavaScript 模块和 GLB。

## 操作

| 模式 | 操作 |
| --- | --- |
| 全城总览 | 鼠标拖动旋转；滚轮缩放；右键拖动平移；触屏双指缩放 |
| 地点选择 | 点击地标或底部的全城总览、灯火长街、宫阙庭院、步入大殿、曲池亭廊 |
| 自由漫游 | WASD / 方向键行走；拖动画面环顾；Shift 快行；滚轮调整视角 |
| 推门参观 | 走近商铺、民居或院门，按 E 开关双扇门；门打开后直接步行进入，原路可以离开 |
| 触屏漫游 | 左下方向键移动，在场景中拖动观察；点击门旁提示开关门 |
| 返回 | Esc 或“返回全城”；点击品牌可恢复全城视角 |
| 透视幻境 | 播放宫殿的推拉变焦镜头，结束后恢复原位置与控制方式 |
| 氛围 | 右侧滑杆调整日暮至夜晚的光照；右上可开启风声与合成檐铃 |

## 模型与实现

- `src/main.js`：总览 / 行走 / 镜头转场的控制权切换、碰撞、光照、界面、触屏与音效。
- `src/city.js`：城墙、城门、街坊、商铺、宫苑、花园与居民；按空间分块、材质合并，并对重复构件复用几何。
- `src/doors.js`：双扇门转轴动画、附近交互、关门阻挡与安全关闭；全城门扉采用共享实例批次。
- `src/garden.js` / `garden-layout.js`：池岸、连续拱桥、亭榭、长廊、共享行走高度与水域碰撞。
- `src/light-optimization.js`：保留 Standard / Physical 材质，只跳过衰减结果为零的点灯直接光计算；与水面波纹 shader 组合。
- `src/building-interiors.js`：茶肆、香铺、布坊、酒家、民居和书舍六类室内，靠近时才生成和显示家具。
- `src/residents.js`：六类百姓，有衣领、袖子、手、发髻和帽子，行走时手脚反相、弯膝抬脚。
- `scripts/build_palace.py`：从 `palace-layout.json` 的共享规格生成 Blender 高低两档大殿模型。
- `assets-source/palace.blend`：可在 Blender 中打开编辑的源文件。
- `public/assets/palace.glb` / `palace-low.glb`：近景 11 万三角面与远景 2.5 万三角面模型；远近切换带滞回，低模合批阴影代理固定日光阴影。
- `public/assets/palace-layout.json`：大殿、三重台基、阶梯、人行高度、镜头和碰撞共享规格；`manifest.json` 收录两档模型统计。
- `assets-source/palace-preview0001.png`：Blender 的制作预览图（最终模型另补充了上部封檐）。

当前正殿由本机 **Blender 5.3** 实际生成并导出；其余城区主要由 Three.js 程序化构建。含元殿殿身约 60 × 34 米、檐顶高约 36 米，站在三重九米台基上；台前有三段阶梯和两段平台，整段登殿纵深约 48 米。台阶可实际步行上下，中央保留 4 米无障碍御道，御道两侧露出更宽的逐级石阶。高模约 3.37 MB，低模约 1.03 MB，均为 13 个材质批次。模型使用米为单位，正面朝 Three.js 的 +Z。

在当前电脑重新生成模型：

以下 `F:\blender\blender.exe` 是作者本机路径，请按实际安装位置替换；网页运行和发布不需要 Blender。

```powershell
& 'F:\blender\blender.exe' --background --factory-startup --gpu-backend opengl --python '.\scripts\build_palace.py'
```

打开可编辑源文件：

```powershell
& 'F:\blender\blender.exe' --gpu-backend opengl '.\assets-source\palace.blend'
```

使用 OpenGL 参数是因为这台电脑上的 Blender 在 Vulkan 初始化时发生崩溃。此参数不影响 GLB 的网页使用。

## 构建与发布

```powershell
npm run build
npm run preview
```

将 **整个 `dist` 目录** 部署到支持静态文件的 HTTP/HTTPS 服务器，保留其中的 `assets` 目录。构建使用相对资源路径，可部署在网站子目录；不依赖后端应用。

`scripts/build.mjs` 将编译器临时文件放在项目 `.tmp` 中，以适配当前电脑共享 TEMP 目录的删除权限。

## 验证

```powershell
npm test
```

自动化测试覆盖真实 WebGL 绘制、总览旋转缩放、地点切换、WASD 行走、建筑碰撞、透视镜头结束归位，以及 390px 触屏布局和光照调整。默认使用系统 Chrome；如系统没有 Chrome，可安装 Playwright 浏览器并修改测试配置。

门交互验收还覆盖关门挡路、E 开门后实际走入商铺、再走出、院墙门往返、门槛防夹、室内开关门与手机点按。室内返回全城时先等待门扉打开，再通过门洞，最后升空转场。

曲池亭廊将旧园林细化为 62 米贯通南北的连续拱桥、119 米连通长廊（24 廊间）与听荷亭、涵碧水榭两座开敞亭。桥面有平滑高度、栏杆及两岸连接，亭廊可连续步行，水域按岸线设置碰撞。原 12 株园林树保留，并增加柳形树、40 片荷叶和荷花；全部构件沿用空间合批，不新增实时反射或点光源。

门闪烁修正分为三处：木门框以 1 厘米实体覆盖墙翼边缘，避开共面深度争夺；门铰内收并在 88.2° 停止，避免厚门扇及横枨转入相邻墙体；室内暖光按每帧渐变，淡出后再移动到下一间房。渲染分辨率和窗口尺寸变更统一排队，在下一帧绘制前一次更新画布及后处理缓冲，避免渲染完后清空 canvas 导致黑帧。

`tests/garden.spec.js` 覆盖桥与亭廊实走及池岸阻挡；`tests/rendering.spec.js` 在普通模式下反复改变 DPR 和窗口大小，检查每次画布重分配均发生于绘制前、呈现帧仍有景物。居民动画只上传可见实例的矩阵与颜色前缀，首次进入房间前还会在加载页以 8×8 离屏渲染预上传共享家具几何。

执行 `node scripts/check-reachability.mjs`，可以按玩家半径 0.48 米、0.4 米网格检查全部 122 间普通建筑的门后点是否与街道连通。此检查将可开关的门视为打开，保留永久墙体和主要家具碰撞；结果写入 `test-results/building-reachability.json`。大殿中央路线另由漫游测试验收。发布版可执行 `node scripts/smoke-dist.mjs` 检查模型和页面资源加载。

路面采用互不重叠的矩形分区，交叉口不再叠两层同深度表面；庭院和基础地面也裁切为互斥区域。总览相机使用更大的近裁剪距离，后处理渲染缓冲开启多重采样，缓解远处瓦线、窗格和地面边缘的抖动；局部灯光保持稳定亮度。

性能侧将静态阳光阴影缓存、全城居民改为按镜头视锥与距离做细节分级并限制骨骼矩阵更新频率，宫殿随距离切换高低模，六类室内模板与材质在打开探索前预热。按本机 AMD 核显、Chrome D3D11、1280 × 900、DPR 1 的 3.3 秒采样，总览由约 34.8 FPS 提至约 50.8 FPS，主街约 41.0 提至 55.9，茶肆首次进入约 48.9 提至 65.9。数值受设备、浏览器和画面内容影响，只代表这组本机条件。

园林扩建前的一轮同条件采样为：总览 60.6 FPS、主街 66.0、宫前 67.8、殿内 43.7，保留在 `reports/performance-v3-baseline.json`。不同运行批次有系统负载差异，不能把跨批次差值全部归因于单一调整。

本轮对零贡献点灯计算先做同一页面、固定相机的原版→优化→原版对照（`reports/light-culling-aba.json`）：宫前约 52.5→69.4→55.3 FPS，园林约 81.0→90.5→78.1；调用和三角面数完全一致。三张原版/优化版对照图中，园林逐像素相同，另两图仅 4 / 8 个像素出现最多 1/255 的通道差；材质、高光、灯光与建筑均保留。正式采用后再按常规漫游采样验收。

园林扩建与正式优化后的最终采样记录于 `reports/performance-v4-final.json`（同步至 `reports/performance-current.json`）：总览 51.4 FPS、主街 52.7、茶肆首次进门 77.2、宫前 70.2、殿内 49.7、园林入口 83.5、桥上 87.8；全部样本无超过 50 ms 的帧，CPU Long Tasks 均为零，加载就绪约 9.4 秒。样本条件仍为本机 AMD 核显 / Chrome D3D11 / 1280 × 900 / DPR 1 / 每处约 3.3 秒。总览及主街视域大仍较重，普通运行时会逐步自适应分辨率；预热将首次探索所需的部分开销移至加载阶段。

## 参考与当前范围

镜头方法参考 [simcraft / perspective-illusion](https://github.com/dotslashsimran/simcraft/tree/58224d131814572224537fb516b8c5d33dd5fa67/skills/video/perspective-illusion) 的推拉变焦与“平面展开为纵深”的设计；本项目使用独立实现的相机系统，没有安装该技能，也不使用其视频导出管线。自由漫游时建筑位置保持固定。

这是一版原创唐风艺术化可玩样板，尚未按历史年代考据。当前 128 栋建筑中有 123 栋可参观（122 间普通建筑一层与主殿），另有可开关的院门；普通室内以六类模板变化组合，二层和塔楼、城楼没有开放参观。已完成总览—长街—庭院—殿内—返回总览的体验链，并支持从街道步行进入大多数商铺与民居。场景并非参考图中 8–12 公里见方的完整城市，后续可继续增加独特建筑、室内陈设、楼梯和楼层。
